# Hands-On Project

## Technical OSINT Profiling & Digital Footprint Analysis

**Objective:**  
Conduct an open-source investigation on a person of interest to gather actionable insights about their background, activities, and online presence to support organizational decision-making.

**Tools Used:**  
Instagram, Facebook, LinkedIn, Twitter, browser research tools, screenshot tools, online verification sources (alumni portals, public records).

**Skills Applied:**  
Social media analysis, digital footprint mapping, fact-checking, OSINT methodology, report writing, ethical intelligence gathering.

**Approach:**  
- Collected and monitored the subject’s social media accounts, posts, stories, comments, and followers.  
- Built a comprehensive profile from publicly available information.  
- Fact-checked key details (e.g., verified graduation status via alumni portal).  
- Captured screenshots and evidence for reporting.  
- Compiled and delivered a structured intelligence report to the supervisor.

**Outcome:**  
- Produced a verified, actionable profile supporting organizational decision-making.  
- Strengthened OSINT and analytical skills.  
- Delivered a professional, evidence-backed report for further organizational action.
