# Mobile Penetration Testing

## 📱 Project: Android App Analysis

**Objective:**  
Reverse engineer an Android APK, perform static analysis, and analyze security findings.

**Steps Taken:**  
1. **Reverse Engineering & Static Analysis:** Decompiled the APK using **MobSF** to inspect the source code and app structure.  
2. **Analysis & Findings:** Examined the app for security issues such as hardcoded keys, insecure storage, or improper permissions. Documented all findings.

**Tool Used:**  
- MobSF  

**Outcome / Learning:**  
- Gained hands-on experience in Android app security testing.  
- Strengthened skills in static analysis and identifying vulnerabilities in mobile applications.
